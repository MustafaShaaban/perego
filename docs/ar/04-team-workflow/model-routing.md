# بوابة توجيه النموذج

هذه الصفحة هي المرآة العربية لسياسة Perego المشتركة. تبقى أسماء الملفات، الأوامر، المتغيرات، أسماء النماذج، ومفاتيح الإعدادات بالإنجليزية.

المصدر الإنجليزي المعياري: [Model Routing Gate](../../en/04-team-workflow/model-routing.md).

ترتيب البوابات هو: Role Gate ثم Model Routing Gate ثم Spec Kit ثم Guard Gate ثم مراجعة UI/UX. لا تستبدل بوابة التوجيه الدستور أو الملكية أو سياسة مساحة العمل الواحدة أو الاختبارات أو الموافقات البشرية.

قبل الاستكشاف الواسع أو التعديل، أعلن المسار بالصيغة التالية:

`MODEL ROUTE — <provider> · <L|M|H|V> · <parent-or-agent> · <configured model/effort> · <reason>`

وعند تغيّره:

`MODEL ROUTE CHANGE — <old> → <new> · <specific trigger>`

المسارات المشتركة هي L للاستكشاف المقيد بالقراءة، وM للعمل الروتيني في الوالد المتوازن، وH لكاتب واحد عالي المخاطر، وV لمراجع عالي القراءة فقط. راجع الجدول والقيود وقواعد التسليم بين المزوّدين وإجراءات التراجع الكاملة في المصدر الإنجليزي. لا تدّعِ تغيير نموذج الوالد أو تأكيد إعداد وقت التشغيل من دون دليل.
