# Acceptance quickstart

1. Build plugin blocks and theme assets.
2. Visit Header, Footer, front page, Client, Service, and Project editors; confirm labels, keyboard traversal, no raw IDs/keys, and real visual previews.
3. Save an unchanged migrated record and compare public EN/AR routes at 1440, 1280, 1024, 768, 430, 375, and 320 pixels.
4. Test header/menu, hero controls, carousels, portfolio selection/grid, forms, lightboxes, sticky/mobile/RTL states.
5. Run Pest, Jest, Playwright/a11y and guards; record screenshots, console errors, overflow, and rollback result.
